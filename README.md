# Синхронизация заказов Яндекс Маркета с Notion

Скрипт по расписанию опрашивает Partner API Яндекс Маркета, находит заказы (FBS/Express)
со статусом `PROCESSING`, которые нужно отгрузить сегодня, и создаёт/обновляет одну
страницу дня в базе данных Notion со списком заказов и товарных позиций.

## Что делает страница дня

- Заголовок: `DD.MM.YYYY — N заказов`.
- Свойство `Date` = сегодняшняя дата — по нему скрипт находит существующую страницу дня.
- Тело страницы: для каждого заказа заголовок `Заказ №{orderId}` и чеклист позиций
  `{название товара} — {артикул/SKU} × {количество}`.
- При повторном запуске страница дня не дублируется: скрипт находит её по дате и
  полностью пересобирает заголовок и содержимое.
- Если заказов на сегодня нет, а страница ещё не создана — она не создаётся. Если
  страница уже есть, заголовок обновится на `DD.MM.YYYY — 0 заказов`, а список очистится.

## 1. Получение токена Яндекс Маркета

1. Зайдите в [кабинет продавца Яндекс Маркета](https://partner.market.yandex.ru/).
2. Откройте раздел **Настройки → API и веб-сервисы** (или **Настройки магазина → API**).
3. Создайте API-ключ (Api-Key токен) для доступа к Partner API.
4. Там же посмотрите **ID кампании (магазина)** — это `YM_CAMPAIGN_ID`.
5. Актуальный список методов и параметров Partner API: https://yandex.ru/dev/market/partner-api/doc/

## 2. Интеграция Notion

1. Откройте https://www.notion.so/my-integrations и нажмите **New integration**.
2. Задайте имя, выберите рабочее пространство, сохраните — получите **Internal Integration Token** (`NOTION_TOKEN`).
3. Создайте в Notion базу данных со свойствами:
   - `Name` — title (уже есть по умолчанию);
   - `Date` — date;
   - `Orders` — number (опционально, скрипт заполнит его, если свойство существует).
4. Откройте базу данных → `•••` в правом верхнем углу → **Connections** → подключите
   созданную интеграцию (это и есть «расшарить базу на интеграцию»).
5. `NOTION_DATABASE_ID` — это ID из URL базы данных:
   `https://www.notion.so/workspace/<NOTION_DATABASE_ID>?v=...` (32 символа, без дефисов
   или с дефисами — оба варианта подходят).

## 3. Переменные окружения

| Переменная | Значение |
| --- | --- |
| `YM_API_KEY` | Api-Key токен Яндекс Маркета |
| `YM_CAMPAIGN_ID` | ID кампании (магазина) |
| `NOTION_TOKEN` | токен интеграции Notion |
| `NOTION_DATABASE_ID` | ID базы данных Notion |
| `TZ_NAME` | таймзона, по умолчанию `Europe/Moscow` |

### Локальный запуск

```bash
npm install
cp .env.example .env   # заполните значения, файл не коммитится (в .gitignore)
npm run sync
```

### GitHub Actions

1. В репозитории откройте **Settings → Secrets and variables → Actions**.
2. Добавьте repository secrets с именами из таблицы выше (`YM_API_KEY`,
   `YM_CAMPAIGN_ID`, `NOTION_TOKEN`, `NOTION_DATABASE_ID`, `TZ_NAME`).
3. Workflow [`.github/workflows/sync.yml`](.github/workflows/sync.yml) запускается по
   cron каждые 15 минут с 06:00 до 20:00 по Europe/Moscow (03:00–17:00 UTC), а также
   вручную через **Actions → Sync Yandex Market orders to Notion → Run workflow**.

## Разработка

```bash
npm install
npm run typecheck   # проверка типов TypeScript
npm test            # юнит-тесты на сборку страницы (моки заказов)
```

Скрипт написан на TypeScript и запускается напрямую через `tsx`, без отдельного шага
сборки. Из внешних зависимостей — только `@notionhq/client`; к Яндекс Маркету
скрипт обращается через встроенный `fetch`.
